File format

MINDPRINT v0.1 is a draft Markdown format for a person's decision and communication preferences. The canonical file is named MINDPRINT.md and starts with:

<!-- mindprint-spec: 0.1 -->

A profile must describe:

  • Scope: supported tasks and coverage limits.
  • Patterns: conditional decision or communication rules.
  • Evidence: stated preferences, observations, or tentative inferences.
  • Exceptions and uncertainty: when a rule does not apply and what is unknown.
  • Authority and precedence: the profile is context, not permission; current instructions and host permissions take precedence.
  • Sharing status: draft, reviewed for a specified audience, or synthetic example.

Attach or paste the file into a text-capable AI. A skill adapter is optional. Native support and behavior vary by host.

Review the exact file before sharing. Remove secrets, identifying source details, and raw conversations. Preferences can still be personal information. A profile does not verify identity or authorize actions on its author's behalf.

Prepare a mindOS build prompt

mindOS is a personal workspace application for web, macOS, or iOS. This page prepares a build prompt for a coding agent; it does not build or host the application.

  1. Create and review your own MINDPRINT.md.
  2. In Create or import a profile, select “Bring my own” and open or paste the file.
  3. Choose a target platform and confirm that the profile is yours.
  4. Select “Prepare my mindOS prompt” and review the complete prompt.
  5. Copy or download it for your coding agent. For web projects, the Lovable link is also available.

The build prompt includes your profile. Opening Lovable passes that prompt in the URL; your chosen provider's policies apply.

Create with AI

The creation prompt directs your AI to use authorized examples or an interview, draft the profile, and ask you to review it.

  1. Copy the creation prompt.
    It points your AI to the MINDPRINT creation skill on GitHub ›.
  2. Send it to your AI.
    Use an agent that knows your work, or let it interview you. Share only the context you choose.
  3. Review your MINDPRINT together.
    Correct the patterns, remove private details, and ask for a finished MINDPRINT.md.
  4. Import the reviewed file.
    Import or paste your reviewed file using “Bring my own.”
