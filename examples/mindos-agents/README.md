# Synthetic decision workspace

This example is not a real person’s approval. Decisions capture a question and a smallest next step; reflections record new evidence. Review the profile, design and fields before using it.

Accept when all platforms use the same labels, token colors and collection IDs; a record created on one client is visible after refresh on another connected to the same backend binding. Check empty, validation-error, offline and expired-session states. Missing connectivity must show an error without pretending to save.
