# MINDPRINT brand assets

A file-first identity for an open-source format. Large plain lettering, readable Markdown, black and white, and one blue accent. The image-generation work follows [Taste Skill brandkit](https://github.com/Leonxlnx/taste-skill/blob/main/skills/brandkit/SKILL.md); copy and production review also use [Impeccable](https://github.com/pbakaus/impeccable).

PNG dimensions are the image generator's actual outputs, not promised platform export presets. The wordmarks use live text with system-font fallbacks; they are not outlined font files. Generated boards are visual references; the JSON is authoritative for exact color values. PNGs were inspected for spelling, composition and clipping. The graphics contain illustrative preferences, not actual personal profiles. No X post was published and no repository social-preview setting was changed.

## Direction

- Lead with `MINDPRINT.md`, a useful example, and a clear next action.
- Keep the wordmark plain. Do not add a fingerprint, brain, robot or other generic AI symbol.
- Use monospace for real Markdown and filenames, not every label.
- Do not imply adoption, compatibility, endorsement or native integration through third-party logo walls.
- Keep profile excerpts explicitly illustrative in surrounding copy.
- Reuse the campaign copy: “Your judgment, in a file.” / “How you think. In plain text.” / “Different minds. One shared context.”
