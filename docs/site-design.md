# Website design

The website has two page families: marketing pages that demonstrate the product, and documentation that supports reading, profile creation handoffs, sharing and mindOS.

See [the design guide](../design.md) for visual conventions, interaction requirements and verification guidance. Semantic marketing tokens live in `website/tokens.css`; the documentation has its own stylesheet.

Use synthetic examples. Preserve read-only profile snapshots and legacy documentation links. Check responsive layouts and affected interactions when making changes.
